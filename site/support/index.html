Femora Plugin Support

Publisher: Amin Pakzad.

For Femora plugin questions, incorrect API suggestions, documentation problems, and bug reports, open an issue in the Femora GitHub repository and identify it as a ChatGPT plugin issue.

Include the prompt, the relevant generated code, expected behavior, and your Femora version. Remove credentials and private data before posting.

Support is provided through the project’s public issue tracker; no response-time commitment is made on this page.

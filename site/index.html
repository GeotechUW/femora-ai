Femora for ChatGPT

Public release in preparation. The build packages are available from the repository’s GitHub Actions runs. The ChatGPT public directory listing has not yet been submitted or published.

Publisher: Amin Pakzad.

Femora helps you write and understand Python code for OpenSees finite element models using bundled Femora API documentation, concept guides, and examples.

It provides coding guidance for meshing, materials, assembly, interfaces, analyses, remote-job workflows, and results. The plugin does not run simulations or submit jobs itself.

This plugin is free to use. ChatGPT access and any computing resources are governed by their respective providers.

Femora Plugin Privacy Policy

Publisher: Amin Pakzad.

This policy covers the Femora AI coding packages, including the ChatGPT plugin, Claude Code plugin, and standalone skill, which consist of bundled instructions and reference files. It does not describe the data practices of all Femora software, websites, or computing services.

Bundled skills and hosted tools

Using the bundled skill files alone does not contact a Femora-operated server. If you connect the optional hosted Femora MCP service, the assistant sends tool inputs such as documentation search text, API symbol names, and reference identifiers to that service, hosted by Render, to retrieve documentation. This does not automatically send the entire conversation.

The service has no user accounts, database, or application-level retention of tool arguments. Application request-body logging and Uvicorn access logging are disabled. Render and network infrastructure may process technical request information under their own policies and configured logging settings. Do not include sensitive or confidential information in documentation queries.

The assistant platform you use processes your conversations under its applicable terms, privacy policy, and your account settings. Using a generated script outside ChatGPT may involve other services and their own data practices.

If you contact support through GitHub, the information you choose to submit is processed under GitHub’s policies and is visible to the issue’s audience. Do not post credentials, private model data, or confidential information in public issues.

The publisher cannot delete records held by your assistant platform or GitHub; use those services’ controls for requests concerning their records.

For plugin privacy questions, use the support page.

This website

These static pages are hosted by GitHub Pages. No additional analytics scripts or forms are included on these pages. GitHub may process technical request information under its own privacy policy.

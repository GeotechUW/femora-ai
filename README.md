# Femora AI

Shared Femora knowledge and platform-specific packages for AI coding assistants.

This repository is being set up to maintain one authoritative set of Femora API references, concept guides, and examples, with platform-specific instructions and release packages for ChatGPT, Claude, and other assistants.

## Planned structure

- Shared knowledge: exact API signatures, concept guides, and worked examples.
- Platform packages: assistant-specific instructions and manifests generated from shared references.
- Build tools: reproducible packaging and validation.
- Public pages: plugin overview, support, privacy, and terms.

## Status

Repository initialization only. Platform packages, public pages, and build tools have not yet been added. This repository does not by itself publish or automatically update a plugin in any assistant platform.
